# 显卡集群虚拟化

围绕显卡集群虚拟化，逐步记录 C 程序调用 CPU、Windows API 与 CUDA Driver API 的实验，并在此基础上开展 GPU 性能测试与后续多卡研究。

## 实验目录

| 实验 | 当前内容 | 入口 |
|---|---|---|
| 01 C 调用 CPU 与 GPU | C 运算与反汇编、内存与文件、线程、CUDA 初始化与向量加法、GPU 线程映射 | [实验说明](labs/01-c-cpu-gpu/README.md) · [12 步图文操作](labs/01-c-cpu-gpu/steps.md) · [Word 报告](labs/01-c-cpu-gpu/reports/C调用CPU与GPU.docx) |

目前收录单机单 GPU 基础实验；多卡调度、资源池和透明虚拟 GPU 功能属于后续研究内容。

## 整理方式

一个实验一个文件夹。该实验的代码、脚本、调试工程、报告和运行结果放在一起。每个新实验先建立自己的目录，再记录过程。

```text
labs/
└─ 01-c-cpu-gpu/
   ├─ README.md       环境、构建与运行说明
   ├─ steps.md        配套原报告的 12 步图文操作
   ├─ src/            C 主机程序和 CUDA 核函数
   ├─ scripts/        构建脚本
   ├─ debug/          Visual Studio 调试工程
   ├─ reports/        原始 Word 报告
   └─ runs/           按实际运行日期保存的日志和截图
```

后续任务继续放在本仓库的 `labs` 中，例如 `02-api-reference`、`03-gpu-stress`。同一个实验重新运行时，在它的 `runs` 中新增批次，保留以前的记录。
